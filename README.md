# Quiz Escolar - Desastres Naturais no Brasil

Site simples em HTML/CSS/JS com tema laranja. Contém 30 perguntas sobre desastres naturais no Brasil; ao iniciar o quiz serão sorteadas 6 perguntas para o usuário responder. Ao final, o sistema apresenta as explicações do porquê da resposta estar certa ou errada.

Como usar

1. Abra `index.html` no navegador (ou ative o GitHub Pages nas configurações do repositório).
2. Clique em "Iniciar Quiz". Você pode preencher seu nome para gerar um embaralhamento reprodutível.
3. Responda as 6 perguntas sorteadas. Ao final, verá o resultado e explicações.

Estrutura do repositório

- index.html — interface principal
- css/styles.css — estilos (tema laranja)
- js/script.js — lógica do quiz
- data/questions.json — 30 perguntas e explicações
- README.md — este arquivo
- LICENSE — licença MIT
